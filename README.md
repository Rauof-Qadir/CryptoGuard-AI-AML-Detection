# CryptoGuard AI

## Crypto Fraud & AML Detection Engine


Machine Learning based Anti Money Laundering system for detecting suspicious cryptocurrency transactions.


## Features


- Transaction anomaly detection
- Isolation Forest based fraud detection
- Behavioral feature engineering
- Graph based transaction analysis
- Risk scoring engine
- Explainable fraud alerts
- Investigation queue


## Architecture


Transaction Data

↓

Feature Engineering

↓

ML Fraud Model

↓

Risk Scoring

↓

Investigation Dashboard


## Machine Learning


Models:

- Isolation Forest
- Rule Based Detection
- Graph Network Analysis


## Risk Output

Risk Level: HIGH
